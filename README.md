## 🎮 Features

- Classic Snake gameplay
- Keyboard controls
- Score tracking
- Random food spawning
- Collision detection
- Game Over screen
- Responsive and lightweight

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/meer-md-shoaib/snake-game.git
```

### 2. Open the project folder

```bash
cd snake-game
```

### 3. Launch the game

Simply open **index.html** in your browser.
